Portal web pendaftaran dan semakan rasmi bagi Kejohanan E-Sports Championship 2026 (Kategori Mobile Legends: Bang Bang & eFootball). Diberdayakan oleh Jawatankuasa Pendaftaran untuk menguruskan maklumat peserta secara *real-time*.

## 🚀 Pautan Rasmi

* 🌐 **Demo Laman Web:** https://08unknown.github.io/MOD-ESports-Portal/

---

## ✨ Ciri-Ciri Utama

- 📱 **Mod Responsive:** Rekabentuk UI berasaskan tema e-sports yang dioptimumkan untuk telefon bimbit, tablet, dan desktop.
- 🛡️ **Pengesahan Peserta:** Sistem log masuk berasaskan No. IC Ketua Pasukan / Peserta untuk semakan maklumat diri dan bukti pembayaran secara selamat.
- ⚡ **Integrasi Cloud Realtime:** Penyelarasan data serta-merta menggunakan Firebase Realtime Database.
- 👨‍💼 **Panel Pentadbir (Admin Dashboard):** Pengurusan rekod peserta, carian pantas, kemaskini nombor telefon, dan kawalan resit pembayaran.

---

## 🛠️ Teknologi Yang Digunakan (Tech Stack)

- **Frontend:** HTML5, JavaScript (ES6+)
- **Rekabentuk UI:** Tailwind CSS, FontAwesome Icons, Google Fonts (Orbitron & Inter)
- **Database:** Firebase Realtime Database
- **Penghosan (Hosting):** GitHub Pages
