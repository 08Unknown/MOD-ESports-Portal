The official web portal for registration and status checks for the 2026 E-Sports Championship (covering the *Mobile Legends: Bang Bang* and *eFootball* categories). Powered by the Registration Committee to manage participant information in real-time.

---

## 🚀 Official Links

* 🌐 **Website Demo:** https://08unknown.github.io/MOD-ESports-Portal/

---

## ✨ Key Features

- 📱 **Mod Responsive:** E-sports-themed UI design optimized for mobile phones, tablets, and desktops.
- 🛡️ **Participant Confirmation:** A login system based on the Team Leader’s or Participant’s IC number, allowing for the secure review of personal information and proof of payment.
- ⚡ **Realtime Cloud Integration:** Instant data alignment using Firebase Realtime Database.
- 👨‍💼 **Admin Dashboard:** Participant record management, quick search, phone number updates, and payment receipt control.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, JavaScript (ES6+)
- **UI Design:** Tailwind CSS, FontAwesome Icons, Google Fonts (Orbitron & Inter)
- **Database:** Firebase Realtime Database
- **Hosting:** GitHub Pages
